Sistema de consultorio medico Web

Para hacer uso de este sistema, debe instalar XAMPP y exportar la base de datos que se encuentra en la ruta /Sistema_consultorio_medico/Sistema_consultorio/DB/consultorio_db esto debe exportarlo a PHPMyadmin.

Despues de eso, subir los archivos a la carpeta htdocs de XAMPP y se ejecutará en la ruta localhost, cada que sea encendido el servidor XAMPP.
